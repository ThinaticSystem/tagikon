# LLM 作業履歴

このディレクトリは LLM セッション（主に Claude Code）による作業履歴を保存する場所。

## 目的

- どのファイルがどういった経緯で作られたかを追跡可能にする
- 設計判断の背景を保全し、後続の LLM セッションが過去のコンテキストを参照できるようにする
- CLAUDE.md（タスク管理特化）と分離することで CLAUDE.md の肥大化を防ぐ

## ファイル一覧

| ファイル                                                     | 内容                                                                    |
| ------------------------------------------------------------ | ----------------------------------------------------------------------- |
| [completed-implementations.md](completed-implementations.md) | 各ファイル単位の実装状況（旧 CLAUDE.md「実装状況 / 完了」テーブル全件） |

## 運用

- セッション間の引き継ぎ情報（完了サマリー・次タスク）は **メモリ** (`~/.claude/projects/-tagikon/memory/`) に書く。このディレクトリには書かない
- `completed-implementations.md` はファイル単位の事実ベース記録。コードの実態と乖離した場合は適時更新する
- 大きな設計判断を伴う作業の議事録は別ファイルとして追加する想定（必要に応じて）

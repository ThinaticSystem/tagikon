# claude-md-maintenance

セッション終了時に CLAUDE.md とメモリを正しく更新する。

## 手順

### 1. セッションの振り返り（必須・更新前に実施）

最初のプロンプトから作業内容を洗い出す:

- **やったこと**: 実際に変更・作成・修正したファイル・機能
- **やらなかったこと**: 指示されたが着手しなかった・できなかったこと（理由も記録）
- **指示がなかったがやったこと**: 作業中に判断して追加した変更（バグ修正・リファクタなど）

この洗い出しが完了してから CLAUDE.md / メモリの更新に進む。

### 2. CLAUDE.md の更新

`/tagikon/CLAUDE.md` を編集する。

**完了テーブルの更新**:

- 完成した実装は「未実装（次に着手）」セクションから「完了」テーブルへ移動する
- 完了テーブルの行は `| ファイルパス | 内容（実装した機能・インターフェース名） |` の形式
- クラス名・関数名・インターフェース名は**コードの実態に合わせた正確な名称**を使う
- 既存行を更新する場合はファイルパスに `（更新）` を追記する

**フェーズチェックリストの更新**:

- 完了したドキュメントフェーズは `- [ ]` → `- [x]` に変更する

**書いてはいけないこと**:

- セッション間の引き継ぎ情報（完了サマリー・次タスク）は CLAUDE.md に書かない → メモリへ

### 3. メモリへの引き継ぎ情報の記録

`~/.claude/projects/-tagikon/memory/project_next-tasks.md` を更新する。

記載すべき内容:

- このセッションで完了した主要な作業（1〜3行）
- 次に着手すべきタスク（CLAUDE.md「未実装」セクションの先頭と対応）
- 未解決の設計上の問題・ブロッカー（あれば）

記載してはいけない内容:

- コードの実装詳細（コードを読めばわかること）
- git ログで追える情報（誰が何を変更したか等）
- 一時的な作業状態（現在の会話内でのみ有効な情報）

## チェックリスト

```
[ ] 振り返り完了（やった / やらなかった / 指示外でやった を洗い出し済み）
[ ] CLAUDE.md 完了テーブル更新済み（新規行 or 既存行更新）
[ ] CLAUDE.md フェーズチェックリスト更新済み（完了フェーズを [x] に）
[ ] メモリ更新済み（project_next-tasks.md に完了サマリーと次タスク記録）
[ ] CLAUDE.md にセッション固有情報が混入していない
```
